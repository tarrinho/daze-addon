Daze tokens

Signs in to Daze and hands back an access token and a refresh token for Home Assistant. Your password is used for the one sign-in request and nothing else.

Open this from your own storage, not from a website. Whoever serves this page controls the code that sees your password, so keep it as a local file. Nothing here is saved: the password is never written to storage, and closing the tab discards everything.
    Paste these into Home Assistant under Settings → Devices & services → Daze. The refresh token is a credential and lasts far longer than the access token — clear your clipboard afterwards, and do not send either through a messaging app.
